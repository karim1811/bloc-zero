Technique

Lancer un noeud IPFS

3 commandes suffisent.

Fonctionne sur Windows, macOS et Linux. Node.js requis.

1 — Installer IPFS
# Via npm
npm install -g ipfs
2 — Initialiser le noeud
ipfs init
3 — Lancer le daemon
ipfs daemon

Ton noeud est actif. Tu peux maintenant épingler des CIDs de Bloc Zéro :
ipfs pin add <CID>
