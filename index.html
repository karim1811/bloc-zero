Comment ça marche

Trois étapes, une archive permanente.

01
Tu envoies ton texte

Un document, un témoignage, un manifeste. N'importe quel texte que tu veux préserver.

02
Il est ancré sur IPFS

Ton fichier reçoit un identifiant unique (CID) et est distribué sur un réseau décentralisé mondial.

03
Il est gravé sur Ethereum

Le CID est enregistré dans dmap — un registre immuable sur la blockchain. Plus personne ne peut l'effacer.

04
Tu as la preuve

Un lien permanent, un CID vérifiable, une trace que tu peux partager n'importe où dans le monde.

Technique · PC allumé

Lancer un nœud IPFS

3 commandes suffit.

# 1. Installer IPFS (Node.js requis)
npm install -g ipfs
 
# 2. Initialiser
ipfs init
 
# 3. Lancer le nœud
ipfs daemon
 
# 4. Épingler les archives Bloc Zéro
ipfs pin add bafkreidvauqcjvdespva2umndhdja3hdl3zyvcca2fx5n6okwrsooxpqse
